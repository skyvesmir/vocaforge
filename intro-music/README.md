# intro-music

紹介動画用のBGM（依頼者がacemusicで生成した曲）と、その解析結果。この動画の制作だけに使う。

- `song.wav` … 曲（44.1kHz・ステレオ・89.11秒）。使うときは、48kHzに変換してよい
- `analysis.json` … 解析結果（修正済みの最新版）

## analysis.json の要点

- テンポ 121.36 BPM。**拍の格子**: `t = 0.226 + 0.4944 × k`（1拍）、**半拍の格子**: `t = 0.226 + 0.2472 × j`。キックの頭に対して約±15ms（30fpsの1フレーム=33ms未満）
- 画面の出現・退場・着地・転換と効果音は、すべて半拍の格子（j）に置く。`snap(t) = 0.226 + 0.2472 × round((t − 0.226) / 0.2472)`
- ハ長調のまま、転調なし
- 音量 -13.0 LUFS（統合）、トゥルーピーク -0.6 dBTP、LRA 3.8 LU。最大の山でも短期ラウドネスは約 -11〜-12 LUFS
- `events` は、格子にスナップ済みの時刻 `t`（半拍の番号 `eighth_index`、元の測定値 `measured_s`）。フェードで変わる所は、測定値に±0.1秒の幅がある
- `sections` は、区間ごとの名前・開始/終了秒・音の特徴（`tone`）・測定値（`measured`）・画面構成の提案（`layout_hint`、`motion_scale_0_1`）
- `expression_1s` は、1秒ごとの音量・明るさ（スペクトル重心）・音の密度（onset数）・低音。0〜1に正規化した列つき。`energy_norm_0_1`（30fps・全体／低音／高域）と合わせて、画面の密度・明るさ・粒子・動きの大きさに連動させる用
- 小節の頭（0拍目か2拍目か）は音の測定では決まらなかった。小節番号は使わず、秒（j）で指定すること
