# intro-music

紹介動画用のBGM（依頼者がacemusicで生成した曲）と、その解析結果。この動画の制作だけに使う。

- `song.wav` … 曲（44.1kHz・ステレオ・89.11秒）。使うときは、48kHzに変換してよい
- `analysis.json` … 解析結果（2回目。1回目の約121.7 BPMは誤りで、正しくは約121.36 BPM）

## analysis.json の要点

- テンポ 121.36 BPM。拍は `t = 0.246 + 0.4944 × k`（k = 0..179）。1拍 0.4944秒、2拍 0.9888秒、4拍 1.9776秒。ずれは±20ms以内
- ハ長調のまま、転調なし
- 音量 -13.0 LUFS（統合）、トゥルーピーク -0.6 dBTP。最大の山でも短期ラウドネスは約 -11〜-12 LUFS
- 区切りは `sections`（名前・開始/終了秒・音量・特徴）と `events`（入り・抜け・一撃の時刻）。誤差は約±0.1秒。キックが入る所（10.12 / 29.88 / 41.25 / 65.52 / 67.46 秒）は拍の格子に乗っている
- 小節の頭（0拍目か2拍目か）は音の測定では決まらなかった。小節番号は使わず、秒で指定すること
- `beat_times_s` は格子の拍の時刻（180個）。`energy_norm_0_1` は30fps・0〜1の音量（全体／低音／高域）
