# APP_CONTRACT — 動画を作る工程と、ビューアの約束事

ビューアは `out/` に置かれたファイルを「見る・ダウンロードする」だけで、動画は作らない。
ファイルはアプリの起動後に置かれる前提で、**リクエストのたびに読む**（ビルド時には読まない）。

## 1. 置き場所（環境変数）

| 環境変数 | 既定 | 意味 |
| :-- | :-- | :-- |
| `OUT_DIR` | `./out` | 成果物のフォルダ（相対パスは、アプリの作業ディレクトリから） |
| `NOTES_PATH` | `./NOTES.md` | 制作メモ（Markdown） |

デモ用の見本は `fixtures/out/` と `fixtures/NOTES.md`（固定の場所。`node scripts/make-fixtures.mjs` で作り直せる）。

## 2. `OUT_DIR` に置けるファイル（すべて、無くてよい）

| ファイル | 役割 |
| :-- | :-- |
| `vocaforge-intro-1080p.mp4` | 最終版（`versions.json` のキーは `final`） |
| `draft-540p.mp4` | 通し版（キーは `draft`） |
| `review-720p.mp4` | 確認用（キーは `review` と仮定） |
| `poster.png` | プレーヤーの poster |
| `contact-sheet.jpg` / `spectrogram.png` | 「ファイル」タブにサムネイルで表示 |
| `metrics.json` | 自由な形の JSON（木で表示） |
| `versions.json` | `{"draft":{"elapsed_min":24},"final":{"elapsed_min":52}}`。項目は欠けてよい |
| `scenes.json` | 下記 |
| `audio/**/*.wav` | `music.wav`、`mix.wav`、`sfx/` の下など（下の階層まで一覧に出す） |

`scenes.json` の形（どの項目も欠けてよい。配列だけの形も読む）:

```json
{"scenes":[{"id":0,"title":"フック","start_s":0,"end_s":10.11,"telop":["…"],"lines":["…"]}]}
```

- `id` が無ければ並び順（0 から）。`start_s` が無いシーンは、押してもジャンプしない。
- `end_s` が無ければ、次のシーンの開始までを、そのシーンとみなす。
- `telop` / `lines` は、文字列の配列（文字列1つでもよい）。
- JSON として読めない（書きかけ）あいだは「無い」のと同じ扱い。

## 3. デモ表示（見本）の決まり

- `OUT_DIR` に **最終版も通し版も無い** あいだはデモ: 画面・API とも `fixtures/out/` と `fixtures/NOTES.md` を **代わりに** 使い、ページの上に帯を出す。
  このあいだ、`OUT_DIR` にある他のファイル（確認用・JSON・音声）は画面に出ない。
- 最終版か通し版の **どちらか1つでも** `OUT_DIR` にあれば、`OUT_DIR` と `NOTES_PATH` だけを使う。見本は一切混ぜない（無いものは「まだありません」）。

## 4. API（すべて `dynamic = 'force-dynamic'`）

| メソッドとパス | 応答 |
| :-- | :-- |
| `GET /api/manifest` | `{ demo, files:[{name,size,mtime}], scenes, metrics, versions }` |
| `GET /api/notes` | 制作メモの本文。`text/markdown; charset=utf-8`。無ければ空文字（200） |
| `GET` / `HEAD /api/files/[...path]` | ファイル本体（ストリーム）。Range 対応 |
| `GET /api/health` | テンプレート既存（DB に `select 1`） |

`/api/manifest` の詳細:

- `demo`: 真偽値。
- `files`: 上の表の既知ファイルのうち、あるもの ＋ `audio/` の下の `.wav`。`name` は `/` 区切りの相対パス、`size` はバイト数、`mtime` は ISO 8601（UTC）。
- `scenes`: そろえた形の配列 `[{id,title,start_s,end_s,telop,lines}]`（欠けた数値は `null`、欠けた配列は `[]`）。`scenes.json` が無い・読めないときは `null`。
- `metrics`: `metrics.json` の中身そのまま。無ければ `null`。
- `versions`: `versions.json` の中身（オブジェクト）。無い・オブジェクトでないときは `null`。

`/api/files/[...path]` の詳細:

- 常に `Accept-Ranges: bytes`。`Range: bytes=a-b` / `a-` / `-n` → `206` と `Content-Range: bytes a-b/全体`、`Content-Length`。範囲外 → `416` と `Content-Range: bytes */全体`。Range なし（または複数範囲・不正な書式）→ `200` で全体。
- `Content-Type` は拡張子から: `mp4`→`video/mp4`、`png`→`image/png`、`jpg`→`image/jpeg`、`json`→`application/json; charset=utf-8`、`wav`→`audio/wav`、`md`→`text/markdown; charset=utf-8`、`txt`→`text/plain; charset=utf-8`。
- `?download=1` → `Content-Disposition: attachment; filename*=UTF-8''<名前>`。
- ほかに `ETag`、`Last-Modified`、`Cache-Control: no-store, no-transform`、`X-Content-Type-Options: nosniff`。`If-Range` が合わなければ全体を返す。
- **404 になるもの**: 無いファイル、ディレクトリ、上の7種類以外の拡張子（`.jpeg` も不可）、`..`・`.`・隠しファイル（`.` 始まり）、絶対パス、`%2e%2e`・`%2F`・`%5C` などエンコードした指定（二重エンコードも）、`\`・`:`・制御文字を含む名前、実体が外にあるシンボリックリンク。
- 例外（アプリ側では変えられない）: エンコードしていない生の `\` を含む URL は、Next.js 本体が先に `308`（`/` に直した URL へ）を返す。その行き先は `404`。
- デモのあいだは、同じ URL が `fixtures/out/` の中身を返す。

## 5. 再現のしかた

```bash
node scripts/make-fixtures.mjs      # fixtures/ を作り直す（ffmpeg-static を使用）
bash scripts/verify.sh              # 起動中の http://localhost:3000 に、curl で一通りの確認
node scripts/make-bundle.mjs        # app-bundle.txt を作り直す
```

## 置いた仮定

1. **デモの条件**: `OUT_DIR` に最終版（`vocaforge-intro-1080p.mp4`）も通し版（`draft-540p.mp4`）も無いあいだはデモ。確認用・JSON・音声だけが置かれた段階は、まだデモのまま（`OUT_DIR` の中身は画面に出ない）。どちらか1つでも置かれたら `OUT_DIR` だけを使い、見本は混ぜない。中身が0バイトでも「ある」と数える。
2. **デモは全部が見本**: デモのあいだは `/api/files` も `fixtures/out/` から返し、制作メモも `fixtures/NOTES.md` を出す。実物があるときの制作メモは `NOTES_PATH` だけ。
3. **manifest の形**: `scenes` は項目をそろえた配列（無ければ `null`）、`metrics` と `versions` は JSON の中身そのまま、`mtime` は ISO 8601（UTC）。`files` は既知の9ファイルのうち、あるもの ＋ `audio/` の下の `.wav`。
4. `versions.json` の確認用のキーは `review` とした（依頼文にあるのは `draft` と `final` だけ）。
5. シーンの時刻は秒のまま（例: 0〜10.11秒）。番号は `id`（無ければ並び順）。`start_s` が無いシーンは押せない。`end_s` が無ければ、次のシーンの開始までを、そのシーンとみなす。
6. 更新時刻は、ブラウザの現地時刻で表示（最初の描画だけ、サーバーの時差で出す）。
7. **制作メモの安全策**: `marked` は字句解析にだけ使い、HTML の文字列を作らず、React の要素に組み立てる。本文中の HTML タグは働かず、文字として出る。リンク先は http / https / mailto と相対パスだけ。画像は読み込まず、リンクにする。
8. 画面の文言は依頼文にある語だけ。失敗の知らせの文言は足していない（「再読み込み」に失敗すると、ボタンの枠が赤くなるだけ）。単位の「秒」、区切りの「・」、KB / MB は付けた。
9. 自動では更新しない（「再読み込み」ボタンか、ブラウザの再読み込み）。
10. 返す拡張子は7種類だけ（`.jpeg` は不可）。隠しファイル、外を指すシンボリックリンクも 404。
11. ファイルの応答は `Cache-Control: no-store, no-transform`（途中で圧縮されると長さが合わなくなるため）。画面からの URL には `?v=更新時刻-サイズ` を付け、差し替わったら読み直す。
12. `scripts/make-fixtures.mjs` は `out/` の中身を消さない（`.gitkeep` が無ければ置くだけ）。`scripts/verify.sh` は `out/` に何かあると、消さないために中止する。
13. `[...path]` を含むパスは作成ツールが受け付けなかったので、そのルートだけシェルから書いた（中身は同じ）。

#!/usr/bin/env node
// 持ち帰り用: テキストのファイルだけを「=== パス ===」の見出しつきで app-bundle.txt に連結する。
// 使い方: node scripts/make-bundle.mjs
// mp4・png などは含めない（fixtures は node scripts/make-fixtures.mjs で作り直せる）。
// node_modules・.next・out/・package-lock.json・.env（接続先）も含めない。
import { readdirSync, readFileSync, statSync, writeFileSync } from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";

const root = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "..");
const TARGET = "app-bundle.txt";
const SKIP_DIRS = new Set(["node_modules", ".next", ".git", ".turbo", ".vercel"]);
const SKIP_FILES = new Set([TARGET, "package-lock.json", ".start_ts", "tsconfig.tsbuildinfo"]);
const TEXT_EXT = new Set([".ts", ".tsx", ".js", ".jsx", ".mjs", ".cjs", ".json", ".md", ".css", ".txt", ".sh", ".yml", ".yaml", ".sql"]);
const TEXT_NAMES = new Set([".gitignore", ".env.example"]);
const MAX_BYTES = 300 * 1024;

function walk(dir, rel) {
  const found = [];
  const entries = readdirSync(dir, { withFileTypes: true }).sort((a, b) => (a.name < b.name ? -1 : a.name > b.name ? 1 : 0));
  for (const e of entries) {
    const r = rel ? `${rel}/${e.name}` : e.name;
    if (e.isDirectory()) {
      if (SKIP_DIRS.has(e.name) || r === "out") continue;
      found.push(...walk(path.join(dir, e.name), r));
    } else if (e.isFile()) {
      found.push(r);
    }
  }
  return found;
}

const parts = [];
const listed = [];
for (const rel of walk(root, "")) {
  const base = path.basename(rel);
  if (SKIP_FILES.has(base)) continue;
  if (base.startsWith(".env") && base !== ".env.example") continue;
  if (!TEXT_EXT.has(path.extname(base).toLowerCase()) && !TEXT_NAMES.has(base)) continue;
  const abs = path.join(root, rel);
  if (statSync(abs).size > MAX_BYTES) continue;
  const text = readFileSync(abs, "utf8");
  if (text.includes("\u0000")) continue;
  parts.push(`=== ${rel} ===\n${text}${text.endsWith("\n") ? "" : "\n"}`);
  listed.push(rel);
}

writeFileSync(path.join(root, TARGET), parts.join("\n"));
console.log(`${TARGET}: ${listed.length} ファイル / ${statSync(path.join(root, TARGET)).size} バイト`);
console.log(listed.join("\n"));

import { open, type FileHandle } from "node:fs/promises";
import { activeRoot, resolveFile } from "@/lib/outdir";

export const dynamic = "force-dynamic";
export const runtime = "nodejs";

const CHUNK = 64 * 1024; // 1回に読む量。ファイル全体はメモリに載せない。

type Ctx = { params: Promise<{ path: string[] }> };

type RangeResult =
  | { kind: "full" }
  | { kind: "partial"; start: number; end: number }
  | { kind: "unsatisfiable" };

function notFound(headOnly: boolean): Response {
  return new Response(headOnly ? null : "Not Found", {
    status: 404,
    headers: {
      "Content-Type": "text/plain; charset=utf-8",
      "Cache-Control": "no-store",
      "X-Content-Type-Options": "nosniff",
    },
  });
}

/** Range ヘッダー（bytes=a-b / a- / -n）。複数範囲や不正な書式は、無視して全体を返す。 */
function parseRange(header: string | null, size: number): RangeResult {
  if (!header) return { kind: "full" };
  const m = /^\s*bytes\s*=\s*(\d*)\s*-\s*(\d*)\s*$/i.exec(header);
  if (!m) return { kind: "full" };
  const a = m[1] ?? "";
  const b = m[2] ?? "";
  if (a === "" && b === "") return { kind: "full" };
  if (a === "") {
    const n = Number(b);
    if (!Number.isSafeInteger(n)) return { kind: "full" };
    if (n === 0 || size === 0) return { kind: "unsatisfiable" };
    return { kind: "partial", start: Math.max(0, size - n), end: size - 1 };
  }
  const start = Number(a);
  if (!Number.isSafeInteger(start)) return { kind: "full" };
  let end = size - 1;
  if (b !== "") {
    const e = Number(b);
    if (!Number.isSafeInteger(e) || e < start) return { kind: "full" };
    end = Math.min(e, size - 1);
  }
  if (start >= size) return { kind: "unsatisfiable" };
  return { kind: "partial", start, end };
}

function encodeFilename(name: string): string {
  return encodeURIComponent(name).replace(/['()*]/g, (c) => `%${c.charCodeAt(0).toString(16).toUpperCase()}`);
}

/** start〜end を、少しずつ読んで流す。読み終わり・中断のどちらでもファイルを閉じる。 */
function streamRange(fh: FileHandle, start: number, end: number, signal: AbortSignal): ReadableStream<Uint8Array> {
  let pos = start;
  let closed = false;
  const closeHandle = async () => {
    if (closed) return;
    closed = true;
    await fh.close().catch(() => {});
  };
  signal.addEventListener("abort", () => void closeHandle(), { once: true });
  return new ReadableStream<Uint8Array>({
    async pull(controller) {
      try {
        const remaining = end - pos + 1;
        if (closed || remaining <= 0) {
          await closeHandle();
          controller.close();
          return;
        }
        const buf = new Uint8Array(Math.min(CHUNK, remaining));
        const { bytesRead } = await fh.read(buf, 0, buf.byteLength, pos);
        if (bytesRead <= 0) {
          await closeHandle();
          controller.close();
          return;
        }
        pos += bytesRead;
        controller.enqueue(bytesRead === buf.byteLength ? buf : buf.subarray(0, bytesRead));
        if (pos > end) {
          await closeHandle();
          controller.close();
        }
      } catch (err) {
        await closeHandle();
        try {
          controller.error(err);
        } catch {
          // すでに閉じている
        }
      }
    },
    async cancel() {
      await closeHandle();
    },
  });
}

async function handle(req: Request, ctx: Ctx, headOnly: boolean): Promise<Response> {
  let segments: string[];
  try {
    segments = (await ctx.params).path;
  } catch {
    return notFound(headOnly);
  }
  const { root } = await activeRoot();
  const file = await resolveFile(root, segments);
  if (!file) return notFound(headOnly);

  let fh: FileHandle;
  try {
    fh = await open(file.abs, "r");
  } catch {
    return notFound(headOnly);
  }

  let handedOver = false;
  try {
    const st = await fh.stat();
    if (!st.isFile()) return notFound(headOnly);
    const size = st.size;
    const lastModified = st.mtime.toUTCString();
    const etag = `"${size.toString(16)}-${Math.floor(st.mtimeMs).toString(16)}"`;

    const headers = new Headers({
      "Content-Type": file.type,
      "Accept-Ranges": "bytes",
      // no-transform: 途中で圧縮されると Content-Length / Content-Range が合わなくなるため
      "Cache-Control": "no-store, no-transform",
      "Last-Modified": lastModified,
      ETag: etag,
      "X-Content-Type-Options": "nosniff",
    });
    if (new URL(req.url).searchParams.get("download") === "1") {
      headers.set("Content-Disposition", `attachment; filename*=UTF-8''${encodeFilename(file.name)}`);
    }

    // If-Range が今のファイルと合わなければ、Range は無視して全体を返す
    const ifRange = req.headers.get("if-range");
    const rangeHeader = ifRange && ifRange !== etag && ifRange !== lastModified ? null : req.headers.get("range");
    const range = parseRange(rangeHeader, size);

    if (range.kind === "unsatisfiable") {
      headers.set("Content-Range", `bytes */${size}`);
      headers.set("Content-Length", "0");
      return new Response(null, { status: 416, headers });
    }

    const start = range.kind === "partial" ? range.start : 0;
    const end = range.kind === "partial" ? range.end : size - 1;
    const length = end - start + 1;
    const status = range.kind === "partial" ? 206 : 200;
    headers.set("Content-Length", String(length));
    if (range.kind === "partial") headers.set("Content-Range", `bytes ${start}-${end}/${size}`);

    if (headOnly || length <= 0) return new Response(null, { status, headers });

    handedOver = true;
    return new Response(streamRange(fh, start, end, req.signal), { status, headers });
  } catch {
    return notFound(headOnly);
  } finally {
    if (!handedOver) await fh.close().catch(() => {});
  }
}

export async function GET(req: Request, ctx: Ctx) {
  return handle(req, ctx, false);
}

export async function HEAD(req: Request, ctx: Ctx) {
  return handle(req, ctx, true);
}

// NOTES.md の表示。
// サニタイズの方針: marked は「字句解析（トークン化）」にだけ使い、HTML 文字列は一切作らない・差し込まない
// （dangerouslySetInnerHTML は使わない）。トークンを React の要素に組み立てるので、
// 本文中の HTML タグ（<script> など）は、タグとしては働かず、そのまま文字として表示される。
// リンク先は http / https / mailto と相対パスだけを通し、javascript: などは捨てる。画像は読み込まず、リンクにする。
import { useMemo, type ReactNode } from "react";
import { marked } from "marked";

type Tok = { type: string; tokens?: Tok[]; [key: string]: unknown };

const ENTITIES: Record<string, string> = { amp: "&", lt: "<", gt: ">", quot: '"', apos: "'", nbsp: "\u00a0" };

const str = (v: unknown): string => (typeof v === "string" ? v : "");

function decodeEntities(s: string): string {
  return s.replace(/&(#[xX][0-9a-fA-F]{1,6}|#\d{1,7}|[a-zA-Z]+);/g, (all: string, body: string) => {
    if (body[0] === "#") {
      const hex = body[1] === "x" || body[1] === "X";
      const code = parseInt(body.slice(hex ? 2 : 1), hex ? 16 : 10);
      if (!Number.isFinite(code) || code <= 0 || code > 0x10ffff) return all;
      try {
        return String.fromCodePoint(code);
      } catch {
        return all;
      }
    }
    return Object.prototype.hasOwnProperty.call(ENTITIES, body) ? ENTITIES[body] : all;
  });
}

/** 通してよいリンク先だけを返す（だめなら null）。 */
export function safeHref(href: unknown): string | null {
  if (typeof href !== "string") return null;
  const s = decodeEntities(href).trim();
  if (s === "") return null;
  // eslint-disable-next-line no-control-regex
  const compact = s.replace(/[\u0000-\u0020\u007f-\u009f]/g, "");
  if (compact.startsWith("//")) return null;
  const m = /^([a-zA-Z][a-zA-Z0-9+.-]*):/.exec(compact);
  if (!m) return s; // 相対パス・ページ内リンク
  const scheme = (m[1] ?? "").toLowerCase();
  return scheme === "http" || scheme === "https" || scheme === "mailto" ? s : null;
}

const hasCheckbox = (toks?: Tok[]): boolean => !!toks && toks.some((x) => x.type === "checkbox" || hasCheckbox(x.tokens));

function checkbox(key: string, checked: unknown): ReactNode {
  return <input key={key} type="checkbox" checked={checked === true} readOnly disabled />;
}

/** 文中の要素。隣り合う文字列は1つにまとめる。 */
function inline(tokens: Tok[] | undefined, kp: string): ReactNode[] {
  const out: ReactNode[] = [];
  const push = (n: ReactNode) => {
    if (typeof n === "string") {
      if (n === "") return;
      const last = out.length - 1;
      const prev = out[last];
      if (typeof prev === "string") {
        out[last] = prev + n;
        return;
      }
    }
    out.push(n);
  };
  (tokens ?? []).forEach((t, i) => {
    const key = `${kp}.${i}`;
    switch (t.type) {
      case "text":
      case "escape":
        if (t.tokens) inline(t.tokens, key).forEach(push);
        else push(decodeEntities(str(t.text)));
        break;
      case "strong":
        push(<strong key={key}>{inline(t.tokens, key)}</strong>);
        break;
      case "em":
        push(<em key={key}>{inline(t.tokens, key)}</em>);
        break;
      case "del":
        push(<del key={key}>{inline(t.tokens, key)}</del>);
        break;
      case "codespan":
        push(<code key={key}>{str(t.text)}</code>);
        break;
      case "br":
        push(<br key={key} />);
        break;
      case "checkbox":
        push(checkbox(key, t.checked));
        break;
      case "link":
      case "image": {
        const href = safeHref(t.href);
        const body: ReactNode =
          t.type === "link" && t.tokens && t.tokens.length > 0 ? inline(t.tokens, key) : str(t.text) || str(t.href);
        if (href) {
          push(
            <a key={key} href={href} target="_blank" rel="noopener noreferrer nofollow">
              {body}
            </a>,
          );
        } else if (Array.isArray(body)) {
          body.forEach(push);
        } else {
          push(body);
        }
        break;
      }
      case "html": {
        // HTML は、タグとして使わず、書かれたとおりの文字として出す（<br> だけは改行にする）
        const raw = str(t.raw) || str(t.text);
        if (/^<br\s*\/?>$/i.test(raw.trim())) push(<br key={key} />);
        else push(raw);
        break;
      }
      default:
        if (t.tokens) inline(t.tokens, key).forEach(push);
        else push(str(t.raw));
    }
  });
  return out;
}

function blocks(tokens: Tok[] | undefined, kp: string): ReactNode[] {
  const out: ReactNode[] = [];
  (tokens ?? []).forEach((t, i) => {
    const key = `${kp}.${i}`;
    switch (t.type) {
      case "space":
        break;
      case "heading": {
        // ページの見出し（h1）の下に入るので、1段下げる（# → h2）
        const depth = Math.min(6, Math.max(1, Number(t.depth) || 1) + 1);
        const Tag = `h${depth}` as "h2" | "h3" | "h4" | "h5" | "h6";
        out.push(<Tag key={key}>{inline(t.tokens, key)}</Tag>);
        break;
      }
      case "paragraph":
        out.push(<p key={key}>{inline(t.tokens, key)}</p>);
        break;
      case "text":
        out.push(...(t.tokens ? inline(t.tokens, key) : [decodeEntities(str(t.text))]));
        break;
      case "checkbox":
        out.push(checkbox(key, t.checked));
        break;
      case "code":
        out.push(
          <pre key={key}>
            <code>{str(t.text)}</code>
          </pre>,
        );
        break;
      case "blockquote":
        out.push(<blockquote key={key}>{blocks(t.tokens, key)}</blockquote>);
        break;
      case "hr":
        out.push(<hr key={key} />);
        break;
      case "list": {
        const items = Array.isArray(t.items) ? (t.items as Tok[]) : [];
        const children = items.map((it, j) => (
          <li key={`${key}.${j}`}>
            {it.task && !hasCheckbox(it.tokens) ? checkbox(`${key}.${j}.c`, it.checked) : null}
            {blocks(it.tokens, `${key}.${j}`)}
          </li>
        ));
        if (t.ordered) {
          out.push(
            <ol key={key} start={typeof t.start === "number" ? t.start : undefined}>
              {children}
            </ol>,
          );
        } else {
          out.push(<ul key={key}>{children}</ul>);
        }
        break;
      }
      case "table": {
        const header = Array.isArray(t.header) ? (t.header as Tok[]) : [];
        const rows = Array.isArray(t.rows) ? (t.rows as Tok[][]) : [];
        const align = Array.isArray(t.align) ? (t.align as unknown[]) : [];
        const cellStyle = (c: number) => {
          const a = align[c];
          return a === "left" || a === "right" || a === "center" ? ({ textAlign: a } as const) : undefined;
        };
        out.push(
          <div className="md-table-wrap" key={key}>
            <table>
              <thead>
                <tr>
                  {header.map((c, j) => (
                    <th key={j} style={cellStyle(j)}>
                      {inline(c.tokens, `${key}.h${j}`)}
                    </th>
                  ))}
                </tr>
              </thead>
              <tbody>
                {rows.map((r, ri) => (
                  <tr key={ri}>
                    {(Array.isArray(r) ? r : []).map((c, j) => (
                      <td key={j} style={cellStyle(j)}>
                        {inline(c.tokens, `${key}.${ri}.${j}`)}
                      </td>
                    ))}
                  </tr>
                ))}
              </tbody>
            </table>
          </div>,
        );
        break;
      }
      case "html": {
        const raw = (str(t.raw) || str(t.text)).trim();
        if (raw !== "") out.push(<p key={key}>{raw}</p>);
        break;
      }
      default: {
        if (t.tokens) out.push(<p key={key}>{inline(t.tokens, key)}</p>);
        else if (str(t.raw).trim() !== "") out.push(<p key={key}>{str(t.raw)}</p>);
      }
    }
  });
  return out;
}

export default function Markdown({ text }: { text: string }) {
  const tokens = useMemo(() => {
    try {
      return marked.lexer(text) as unknown as Tok[];
    } catch {
      return null;
    }
  }, [text]);
  if (!tokens) return <pre className="raw-json">{text}</pre>;
  return <div className="md">{blocks(tokens, "b")}</div>;
}

function TreeNode({ name, value, depth }: { name: string; value: unknown; depth: number }) {
  if ((Array.isArray(value) || isRecord(value)) && depth < MAX_DEPTH) {
    const isArr = Array.isArray(value);
    const entries: [string, unknown][] = isArr
      ? (value as unknown[]).map((v, i): [string, unknown] => [String(i), v])
      : Object.entries(value as Record<string, unknown>);
    const shown = entries.slice(0, MAX_CHILDREN);
    return (
      <details className="tree-node" open={depth < 2}>
        <summary>
          <span className="tree-key">{name}</span>
          <span className="tree-count">{isArr ? `[${entries.length}]` : `{${entries.length}}`}</span>
        </summary>
        <div className="tree-children">
          {shown.map(([k, v]) => (
            <TreeNode key={k} name={k} value={v} depth={depth + 1} />
          ))}
          {entries.length > shown.length && (
            <div className="kv">
              <span className="kv-key">…</span>
              <span className="kv-val num">{`+${entries.length - shown.length}`}</span>
            </div>
          )}
        </div>
      </details>
    );
  }
  const isNum = typeof value === "number";
  const text = typeof value === "string" ? value : value === undefined ? "" : JSON.stringify(value);
  return (
    <div className="kv">
      <span className="kv-key">{name}</span>
      <span className={isNum ? "kv-val num" : "kv-val"}>{text}</span>
    </div>
  );
}

    const st = await fs.stat(path.join(/* turbopackIgnore: true */ root, rel));
    if (!st.isFile()) return null;
    return { name: rel, size: st.size, mtime: st.mtime.toISOString() };
  } catch {
    return null;
  }
}

/** audio/ の下の .wav を、下の階層（sfx/ など）まで集める。 */
async function listWavs(root: string, relDir: string, depth: number, acc: FileEntry[]): Promise<FileEntry[]> {
  if (depth > 4 || acc.length >= MAX_AUDIO_FILES) return acc;
  let entries;
  try {
    entries = await fs.readdir(path.join(/* turbopackIgnore: true */ root, relDir), { withFileTypes: true });
  } catch {
    return acc;
  }
  entries.sort((a, b) => (a.name < b.name ? -1 : a.name > b.name ? 1 : 0));
  for (const e of entries) {
    if (e.name.startsWith(".") || acc.length >= MAX_AUDIO_FILES) continue;
    const rel = `${relDir}/${e.name}`;
    if (e.isDirectory()) {
      await listWavs(root, rel, depth + 1, acc);
    } else if (e.isFile() && e.name.toLowerCase().endsWith(".wav")) {
      const entry = await statEntry(root, rel);
      if (entry) acc.push(entry);
    }
  }
  return acc;
}

/** JSON を読む。無い・大きすぎる・壊れている（書きかけ）ときは null。 */
async function readJson(root: string, rel: string): Promise<unknown> {
  try {
    const p = path.join(/* turbopackIgnore: true */ root, rel);
    const st = await fs.stat(p);
    if (!st.isFile() || st.size > MAX_JSON_BYTES) return null;
    let text = await fs.readFile(p, "utf8");
    if (text.charCodeAt(0) === 0xfeff) text = text.slice(1);
    const parsed: unknown = JSON.parse(text);
    return parsed === undefined ? null : parsed;
  } catch {
    return null;
  }
}

export async function getManifest(active?: ActiveRoot): Promise<Manifest> {
  const { demo, root } = active ?? (await activeRoot());
  const [known, wavs, scenesRaw, metrics, versionsRaw] = await Promise.all([
    Promise.all(KNOWN_FILES.map((name) => statEntry(root, name))),
    listWavs(root, "audio", 0, []),
    readJson(root, "scenes.json"),
    readJson(root, "metrics.json"),
    readJson(root, "versions.json"),
  ]);
  const files: FileEntry[] = [];
  for (const f of known) if (f) files.push(f);
  files.push(...wavs);
  return {
    demo,
    files,
    scenes: normalizeScenes(scenesRaw),
    metrics: metrics ?? null,
    versions: isRecord(versionsRaw) ? versionsRaw : null,
  };
}

/** 制作メモの本文。デモのときは fixtures/NOTES.md、それ以外は NOTES_PATH。無ければ空文字。 */
export async function getNotes(active?: ActiveRoot): Promise<string> {
  const { demo } = active ?? (await activeRoot());
  const p = demo ? fixturesNotesPath() : notesPath();
  try {
    const st = await fs.stat(p);
    if (!st.isFile()) return "";
    let text: string;
    if (st.size > MAX_NOTES_BYTES) {
      const fh = await fs.open(p, "r");
      try {
        const buf = Buffer.alloc(MAX_NOTES_BYTES);
        const { bytesRead } = await fh.read(buf, 0, MAX_NOTES_BYTES, 0);
        text = buf.subarray(0, bytesRead).toString("utf8");
      } finally {
        await fh.close();
      }
    } else {
      text = await fs.readFile(p, "utf8");
    }
    return text.charCodeAt(0) === 0xfeff ? text.slice(1) : text;
  } catch {
    return "";
  }
}

export type ResolvedFile = { abs: string; name: string; type: string };

/** 何重かにエンコードされた指定（%252e など）も、ほどいてから調べる。 */
function decodeSegment(seg: string): string | null {
  let cur = seg;
  for (let i = 0; i < 4; i++) {
    let next: string;
    try {
      next = decodeURIComponent(cur);
    } catch {
      return cur; // % を含むだけの、ふつうの名前として扱う
    }
    if (next === cur) return cur;
    cur = next;
  }
  return null;
}

/**
 * /api/files/[...path] の指定を、root の中の実在するファイルに解決する。だめなら null（→ 404）。
 * - 「..」「.」・隠しファイル・「/」「\」「:」・制御文字を含む区間は不可（絶対パス・%2e%2e・バックスラッシュ対策）
 * - 拡張子は MIME にある7種類だけ
 * - シンボリックリンクをたどった実体が root の外なら不可
 * - ディレクトリは不可
 */
export async function resolveFile(root: string, segments: readonly string[]): Promise<ResolvedFile | null> {
  if (!Array.isArray(segments) || segments.length === 0 || segments.length > 16) return null;
  const parts: string[] = [];
  for (const raw of segments) {
    if (typeof raw !== "string") return null;
    const seg = decodeSegment(raw);
    if (seg === null || seg === "" || seg.length > 255) return null;
    if (seg === "." || seg === ".." || seg.startsWith(".")) return null;
    // eslint-disable-next-line no-control-regex
    if (/[\\/:\u0000-\u001f\u007f]/.test(seg)) return null;
    parts.push(seg);
  }
  const name = parts[parts.length - 1];
  const ext = path.extname(name).toLowerCase();
  if (!Object.prototype.hasOwnProperty.call(MIME, ext)) return null;
  const abs = path.resolve(/* turbopackIgnore: true */ root, ...parts);
  if (!abs.startsWith(root + path.sep)) return null;
  try {
    const [realRoot, real] = await Promise.all([fs.realpath(root), fs.realpath(abs)]);
    if (!real.startsWith(realRoot + path.sep)) return null;
    const st = await fs.stat(real);
    if (!st.isFile()) return null;
    return { abs: real, name, type: MIME[ext] };
  } catch {
    return null;
  }
}

export function isRecord(v: unknown): v is Record<string, unknown> {
  return typeof v === "object" && v !== null && !Array.isArray(v);

function toNumber(v: unknown): number | null {
  if (typeof v === "number") return Number.isFinite(v) ? v : null;
  if (typeof v === "string" && v.trim() !== "") {
    const n = Number(v);
    return Number.isFinite(n) ? n : null;
  }
  return null;
}

function toStringList(v: unknown): string[] {
  if (typeof v === "string") return v === "" ? [] : [v];
  if (!Array.isArray(v)) return [];
  const out: string[] = [];
  for (const x of v) {
    if (typeof x === "string") {
      if (x !== "") out.push(x);
    } else if (typeof x === "number" && Number.isFinite(x)) {
      out.push(String(x));
    }
  }
  return out;
}

/**
 * scenes.json の中身を、どの項目が欠けていても落ちない形にそろえる。
 * ファイルが無い・JSONとして読めないとき（null）は null のまま返す。
 * {"scenes":[…]} の形のほか、配列だけの形も受け付ける。
 */
export function normalizeScenes(raw: unknown): Scene[] | null {
  if (raw === null || raw === undefined) return null;
  let list: unknown[] = [];
  if (Array.isArray(raw)) list = raw;
  else if (isRecord(raw) && Array.isArray(raw.scenes)) list = raw.scenes;
  return list.slice(0, 2000).map((item, i) => {
    const o = isRecord(item) ? item : {};
    let id: number | string = i;
    if (typeof o.id === "number" && Number.isFinite(o.id)) id = o.id;
    else if (typeof o.id === "string" && o.id !== "") id = o.id;
    return {
      id,
      title: typeof o.title === "string" ? o.title : "",
      start_s: toNumber(o.start_s),
      end_s: toNumber(o.end_s),
      telop: toStringList(o.telop),
      lines: toStringList(o.lines),
    };
  });
}

/** /api/manifest の応答を、形が崩れていても落ちないように受け取る。 */
export function coerceManifest(x: unknown): Manifest {
  const m = isRecord(x) ? x : {};
  const files: FileEntry[] = [];
  if (Array.isArray(m.files)) {
    for (const f of m.files) {
      if (isRecord(f) && typeof f.name === "string" && f.name !== "") {
        files.push({
          name: f.name,
          size: typeof f.size === "number" && Number.isFinite(f.size) ? f.size : 0,
          mtime: typeof f.mtime === "string" ? f.mtime : "",

      }
    }
  }
  return {
    demo: m.demo === true,
    files,
    scenes: normalizeScenes(m.scenes),
    metrics: m.metrics === undefined ? null : m.metrics,
    versions: isRecord(m.versions) ? m.versions : null,
  };
}

/** いま再生している位置のシーン（無ければ -1）。end_s が無いシーンは、次のシーンの開始までとみなす。 */
export function findSceneIndex(scenes: Scene[] | null, t: number): number {
  if (!scenes || !Number.isFinite(t)) return -1;
  const tt = t + 0.02; // ジャンプ直後の、わずかな誤差を吸収する
  let found = -1;
  for (let i = 0; i < scenes.length; i++) {
    const start = scenes[i].start_s;
    if (start === null) continue;
    let end = scenes[i].end_s;
    if (end === null) {
      end = Infinity;
      for (let j = i + 1; j < scenes.length; j++) {
        const next = scenes[j].start_s;
        if (next !== null && next > start) {
          end = next;
          break;
        }
      }
    }
    if (tt >= start && tt < end) found = i;
  }
  return found;
}

export function formatBytes(n: number): string {
  if (!Number.isFinite(n) || n < 0) return "—";
  if (n < 1024) return `${n} B`;
  const units = ["KB", "MB", "GB", "TB"];
  let v = n / 1024;
  let i = 0;
  while (v >= 1024 && i < units.length - 1) {
    v /= 1024;
    i++;
  }
  return `${v >= 100 ? v.toFixed(0) : v.toFixed(1)} ${units[i]}`;
}

const pad2 = (n: number) => String(n).padStart(2, "0");

/**
 * 更新時刻の表示（YYYY-MM-DD HH:mm）。
 * offsetMin は Date#getTimezoneOffset() と同じ向き（日本時間なら -540）。null なら、その環境の現地時刻。
 * サーバーとブラウザで最初の描画をそろえるため、最初はサーバーの時差を渡し、あとでブラウザの現地時刻に直す。
 */
export function formatDateTime(iso: string, offsetMin: number | null): string {
  const t = Date.parse(iso);
  if (!Number.isFinite(t)) return "—";
  const off = offsetMin === null ? new Date(t).getTimezoneOffset() : offsetMin;
  const d = new Date(t - off * 60000);
  return `${d.getUTCFullYear()}-${pad2(d.getUTCMonth() + 1)}-${pad2(d.getUTCDate())} ${pad2(d.getUTCHours())}:${pad2(d.getUTCMinutes())}`;
}

const sec = (n: number | null) => (n === null || !Number.isFinite(n) ? "—" : String(Math.round(n * 100) / 100));

/** シーンの区間（start_s〜end_s、秒）。 */
export function formatRange(start: number | null, end: number | null): string {
  if (start === null && end === null) return "—";
  return `${sec(start)}〜${sec(end)}秒`;
}
