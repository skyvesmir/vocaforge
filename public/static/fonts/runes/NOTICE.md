# Font attribution and terms

This package's MIT license does **not** cover the font files in this directory.
They are fan-made fonts, downloaded from the Puella Magi Wiki and included here
under the same terms the wiki shares them under.

## Underlying work

The Witch Runes (魔女文字) were designed by **Inu Curry** (劇団イヌカレー) for
[*Puella Magi Madoka Magica*](https://www.madoka-magica.com).

Aniplex, MBS, Shaft, Inu Curry, or anyone else who owns rights to the series.

## Bundled fonts

### MadokaRunes-2.0.ttf (archaic and modern variants)

- Version 2.0, 11 November 2011
- Made with FontForge. The font metadata names no author.
- From <https://wiki.puella-magi.net/Community:Fanworks>

### MadokaMusical.ttf (musical variant)

- Made by **kFYatek** with FontForge, 3 October 2011
- From <https://wiki.puella-magi.net/Community:Fanworks>

### MajoPMMM6.ttf (Latin variant)

- Adapted from official *Puella Magi Madoka Magica* material by
  **[User:EPF](https://wiki.puella-magi.net/User:EPF)**, 1 March 2026
- From <https://wiki.puella-magi.net/Community:Fanworks>

The `.woff2` files are just the `.ttf` files converted by
`scripts/build-fonts.mjs`. The glyphs are untouched.

## Use

These are fan fonts, so use them the way the wiki shares them: fan projects,
personal sites, anything non-commercial. None of them comes with a real font
license, so ask the rights holders first if you want to use them commercially.
If you pass the fonts on to someone else, include this file with them.

This directory holds only the `.woff2` files, copied unmodified from
